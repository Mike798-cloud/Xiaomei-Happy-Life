# 小美の快乐家园

> 来找我玩呀～来找我玩呀～不要走～

一款纯网页的**第一人称心理恐怖解谜游戏**。深夜，你点开一个 2003 年的儿童个人主页，成为计数器上的第 `000113` 位「没能离开的人」。前期恐怖，后期哀伤。

- **在线游玩**：部署 GitHub Pages 后，地址为 `https://<你的用户名>.github.io/xiaomei-happy-home/`
- **通关时长**：单周目约 70–85 分钟，三结局 + 全收集约 90 分钟
- **结局数量**：3 个（轮回 / 留下 / 我记得）

## 本地运行

无需安装任何环境、无需构建：

1. 下载或克隆本仓库；
2. 直接双击 `index.html`，用浏览器打开即可游玩。

> 推荐使用最新版 Chrome / Edge / Firefox / Safari，建议佩戴耳机、深夜独自游玩。

## 操作说明

| 操作 | 方式 |
| --- | --- |
| 观察 / 移动视角 | 移动鼠标 |
| 互动 / 拾取 / 进入 | 鼠标左键点击发光热点 |
| 背包 | 点击屏幕边缘背包条，或按 `I` 键 |
| 暂停 / 设置 | 按 `Esc`，或点击「开始菜单」 |
| 拖拽（拼字 / 折纸 / 仪式） | 按住拖动（支持触屏） |

卡关时会自动出现三级提示，也可在暂停菜单主动要提示。

## 内容警告

本游戏包含恐怖形象、突发惊吓、血迹、火灾与儿童死亡等主题，建议 **15 岁以上**、无心脏病及惊吓诱发史的玩家游玩。游戏提供「光敏保护模式」与「减少惊吓模式」，可在设置中随时开启。

## 技术栈

纯静态：`HTML5 + CSS3 + 原生 JavaScript (ES6+)`，音乐与音效由 Web Audio API 实时合成，无任何外部素材依赖、无后端、无数据库。

## 目录结构

```
xiaomei-happy-home/
├── index.html            # 游戏入口
├── 404.html              # 定制 404 彩蛋
├── assets/
│   ├── css/              # 双世界样式与滤镜
│   ├── js/               # 引擎、谜题、场景
│   ├── data/             # 剧本与谜题数据
│   ├── img/  audio/      # 预留素材目录（本作视觉/音频均由代码生成）
└── docs/                 # 策划案与素材许可台账
```

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "feat: 小美の快乐家园"
git branch -M main
git remote add origin https://github.com/<你的用户名>/xiaomei-happy-home.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 中选择 `main` 分支、根目录，保存后等待 1–2 分钟即可获得在线地址。
